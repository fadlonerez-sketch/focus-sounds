## Processing and reproducibility

- `python tools/generate_noise.py` regenerates both noise files deterministically (fixed seeds).
- `python tools/build_recordings.py` downloads the three sources (hash-verified) and rebuilds the loops.
- `python tools/analyze_recording.py <file>` produced the steadiness measurements used to pick sections.
- Requires Python 3 + numpy and ffmpeg (on PATH or `FFMPEG_DIR`).

## Known limitation

Freesound only serves original files (WAV/FLAC) to logged-in users. The three recordings were built
from Freesound's public 192 kbps Ogg Vorbis previews. To upgrade, download the originals while logged
in, save them in `tools/sources/` and update `SOURCES` in `tools/build_recordings.py` (file name,
SHA-256 and section offsets). The license is the same CC0 for the original file.
